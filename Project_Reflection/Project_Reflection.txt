# บันทึกการสะท้อนคิดและการเรียนรู้ (Learning Reflection)
## โครงการพัฒนาระบบแดชบอร์ดสภาพอากาศและคุณภาพอากาศ: WeatherAQI Sense
**รายวิชา:** CP352301 การเขียนโปรแกรมสคริปต์ (Scripting Language Programming)  
**คณะผู้จัดทำ:** สหกานต์ธีรา สังข์ขาว (ผักกาด), ปิยภัทร รัตนรักษ์ (พัตเตอร์), อัษฎาวุธ เรือนแก้ว (กล้า)  

---

### บทนำ (Executive Summary)
การพัฒนาเว็บไซต์และระบบ **WeatherAQI Sense** ไม่ได้เป็นเพียงแค่การเขียนสคริปต์ส่งงานตามข้อกำหนดของรายวิชา แต่เป็นประสบการณ์การเรียนรู้เชิงลึก (Deep Learning Experience) ที่หล่อหลอมให้พวกเราได้สัมผัสวงจรการพัฒนาซอฟต์แวร์จริงในรูปแบบ **Full-Stack Software Engineering** ตั้งแต่โครงสร้าง Command Line Interface (CLI) บนเครื่องคอมพิวเตอร์ส่วนบุคคล ไปจนถึงการย้ายระบบขึ้น Cloud Database และการสร้าง Web Dashboard ที่แสดงผลสด 78 จังหวัดทั่วประเทศไทย พร้อมระบบส่งมอบอัตโนมัติ (CI/CD Pipeline)

การได้ลงมือปฏิบัติจริงในโครงการนี้สร้างประโยชน์และการเรียนรู้รอบด้าน สรุปออกเป็นมิติต่าง ๆ ดังนี้:

---

### 1. การเรียนรู้ด้านสถาปัตยกรรมซอฟต์แวร์และการเขียนโปรแกรม (Software Engineering & OOP)
* **การออกแบบโครงสร้างแบบแยกชั้น (Layered Modular Architecture):**  
  ได้เรียนรู้การแบ่งหน้าที่ของระบบ (Separation of Concerns) ตามหลัก **Single Responsibility Principle (SRP)** โดยแยกโค้ดออกเป็น 3 ชั้นหลักอย่างชัดเจน:
  1. *Presentation Layer:* ส่วนปฏิสัมพันธ์กับผู้ใช้ (`cli_app.py`, `index.html`)
  2. *Business Logic Layer:* ตรรกะการประมวลผลและการตัดสินใจ (`ai_advisory.py`, `report_generator.py`)
  3. *Data Access Layer:* การเข้าถึงและจัดการข้อมูล (`weather_client.py`, `data_store.py`)  
  สถาปัตยกรรมนี้ทำให้เราเห็นข้อดีอย่างแท้จริงของการไม่ใช้ตัวแปรแบบ `global` ซึ่งช่วยให้โค้ดมีความปลอดภัย ยืดหยุ่น แก้ไขง่าย และรองรับการทำ Unit Test ได้อย่างราบรื่น
* **การเขียนโปรแกรมเชิงป้องกัน (Defensive Programming & Resilience):**  
  ได้เรียนรู้วิธีรับมือกับความไม่แน่นอนของเครือข่ายและ Third-party API โดยออกแบบระบบ **Mock Fallback Mechanism** เมื่อ API ปลายทางล่ม หรือเมื่อไม่มี API Key โปรแกรมยังคงทำงานต่อเนื่องได้โดยไม่เกิด Crash ซึ่งเป็นหัวใจสำคัญของซอฟต์แวร์ระดับมืออาชีพ
* **การจัดการข้อมูลเชิงสัมพันธ์ (CRUD, Search, Filter, Sort):**  
  ได้ฝึกการเขียนอัลกอริทึมจัดการข้อมูลที่ครบวงจรทั้งการสร้าง (Create), อ่าน (Read), ปรับปรุง (Update), ลบ (Delete) ตลอดจนการทำ Parameterized Query ด้วย SQL เพื่อป้องกันช่องโหว่ SQL Injection พร้อมพัฒนาฟังก์ชันค้นหา (SQL LIKE), กรองหลายเงื่อนไข (Multi-criteria Filter) และเรียงลำดับข้อมูลอย่างมีประสิทธิภาพ

### 2. การเรียนรู้ด้านเทคโนโลยีเว็บสมัยใหม่และประสบการณ์ผู้ใช้ (Modern Web & UX/UI Design)
* **การออกแบบส่วนติดต่อผู้ใช้สไตล์ Glassmorphism:**  
  ได้เรียนรู้หลักการออกแบบหน้าเว็บที่ทันสมัย การใช้กระจกเบลอ (Backdrop Blur), แสงเงา (Box Shadows) และการจับคู่สีแบบ Gradient ที่สอดคล้องกับสภาพอากาศ ทำให้แดชบอร์ดดูมีระดับ สบายตา และดึงดูดผู้ใช้งาน
* **การสร้างความเข้าใจผ่านภาพ (Data Visualization):**  
  ได้เรียนรู้การแปลงตัวเลขดิบด้านอุตุนิยมวิทยาและสารมลพิษให้กลายเป็นสารสนเทศที่มองเห็นได้ง่าย ผ่านทั้ง **Chart.js** บนหน้าเว็บ (แสดงแนวโน้มอุณหภูมิและ AQI รายชั่วโมง) และ **Matplotlib Dual-Axis Chart** บนฝั่ง Python ซึ่งฝึกทักษะการเลือกใช้ชนิดกราฟและแกน Y สองแกนเพื่อเปรียบเทียบข้อมูลคนละหน่วยวัดได้อย่างถูกต้อง
* **การออกแบบเพื่อผู้ใช้งานทุกคน (Responsive & Bilingual Support):**  
  ได้เรียนรู้การจัดการ Local Storage และการออกแบบระบบสลับภาษา (TH/EN Toggle) ที่เปลี่ยนข้อความ ป้ายกำกับ และคำแนะนำสุขภาพได้ทันทีโดยไม่ต้องโหลดหน้าเว็บใหม่ รวมถึงการจัดวาง Layout แบบ Responsive ที่รองรับทั้งหน้าจอสมาร์ตโฟน แท็บเล็ต และคอมพิวเตอร์เดสก์ท็อป

### 3. การเรียนรู้ด้านฐานข้อมูลคลาวด์และไปป์ไลน์ข้อมูล (Cloud Database & Data Pipelines)
* **การย้ายระบบจาก Local สู่ Cloud (SQLite to Supabase PostgreSQL):**  
  ได้เห็นภาพจริงของกระบวนการ **Database Migration** จากการเก็บข้อมูลแบบ Local File (`.db`) ขยับขยายไปสู่ Cloud Database Service (Supabase) ผ่านการออกแบบ Database Schema, Primary Keys, Constraints และการจัดการ Policy การเข้าถึงข้อมูล
* **การทำ Caching Layer เพื่อประสิทธิภาพและความคุ้มค่า:**  
  ได้เรียนรู้การวางกลยุทธ์ลดต้นทุนการเรียกใช้ API (API Rate Limit / Quota) โดยการบันทึก Cache ข้อมูล 78 จังหวัดไว้บนคลาวด์ และทำระบบสลับโหมดอัตโนมัติ (`● CACHE` / `● LIVE`) เพื่อให้เว็บโหลดเร็วที่สุดและประหยัดทรัพยากร
* **การประมวลผลแบบอะซิงโครนัส (Asynchronous Programming):**  
  ได้พัฒนาสคริปต์ดึงข้อมูลแบบขนานผ่าน `asyncio` และ `aiohttp` ใน Python ช่วยย่นระยะเวลาการดึงข้อมูลทั้ง 78 จังหวัดจากเดิมที่ต้องรอนานหลายสิบวินาที ให้เสร็จสิ้นได้ในเวลาเพียงเสี้ยววินาที

---

### 4. การเรียนรู้ด้านการประกันคุณภาพและ DevOps (QA, Automated Testing & CI/CD)
* **ความสำคัญของการเขียนชุดทดสอบ (Automated Unit Testing):**  
  ได้ฝึกการเขียน Test Cases ครอบคลุมถึง 44-62 กรณีทดสอบด้วย `pytest` รวมถึงการเจาะลึกทดสอบ **Edge Cases** และ **Boundary Values** (เช่น AQI ขอบเขต 0, 50, 51, 100, 300, 999 หรืออุณหภูมิติดลบ) ทำให้เข้าใจว่าโค้ดที่ดีต้องผ่านการพิสูจน์ความถูกต้อง ไม่ใช่เพียงแค่เขียนแล้วรันผ่านครั้งเดียว
* **การรักษามาตรฐานโค้ดด้วย Linting (Code Hygiene):**  
  ได้ฝึกฝนวินัยในการเขียนโค้ดตามมาตรฐาน PEP 8 โดยใช้ `flake8` ตรวจจับข้อผิดพลาด จัดการช่องว่าง และความยาวบรรทัดจนผ่านเกณฑ์ 0 Errors 100%
* **การสร้างระบบส่งมอบอัตโนมัติ (CI/CD Pipeline with GitHub Actions):**  
  ได้สัมผัสการทำ DevOps อย่างเป็นรูปธรรม ผ่านการเขียน GitHub Actions Workflow:
  - ตรวจสอบ Linting และ Unit Test อัตโนมัติทุกครั้งที่มีการ Git Push หรือ Pull Request
  - สั่งรัน Cron Job อัปเดตข้อมูลสภาพอากาศสดลงฐานข้อมูลอัตโนมัติ
  - สั่ง Deploy ตัวเว็บไปยัง **GitHub Pages** อัตโนมัติทันทีที่โค้ดผ่านการทดสอบ

### 5. การเรียนรู้การทำงานร่วมกับปัญญาประดิษฐ์ (Responsible AI & Prompt Engineering)
* **การใช้ AI ในฐานะคู่คิดพัฒนา (Pair Programmer):**  
  ได้ฝึกการตั้งคำถาม (Prompting) เชิงเทคนิคอย่างแม่นยำ เช่น การขอคำแนะนำเรื่อง Dual-Axis Plotting, การทำ Defensive Input Normalization และการออกแบบ Schema
* **หลักการ Explainable & Verifiable AI:**  
  ได้ตระหนักว่าเราต้องไม่เชื่อผลลัพธ์ของ AI โดยปราศจากการตรวจสอบ จึงได้จัดทำเอกสาร `LEARNINGLOG.md` และ Jupyter Notebook เพื่อบันทึกคำสั่ง ตรวจสอบตรรกะเบื้องหลัง และรัน Live Verification Code พิสูจน์ความถูกต้องของโค้ดทุกส่วนด้วยตัวเราเองเสมอ

---

### 6. การเรียนรู้ด้านการบริหารจัดการและทักษะการทำงานเป็นทีม (Agile & Soft Skills)
* **การหมุนเวียนบทบาท (Role Rotation Matrix):**  
  การที่พวกเราทั้ง 3 คน (ผักกาด, พัตเตอร์, กล้า) ได้ผลัดเปลี่ยนหน้าที่กันในทั้ง 3 Sprints:
  - ทำให้ทุกคนได้เป็นทั้ง **Planner/Architect** (ฝึกการวางผัง มองภาพรวม จัดสรรงาน)
  - ได้เป็นทั้ง **Coder/Dev** (ฝึกเขียนโค้ดแก้ปัญหาจริง ลงมือสร้างชิ้นงาน)
  - และได้เป็นทั้ง **Debugger/QA/DevOps** (ฝึกทดสอบ หาจุดบกพร่อง ตรวจสอบความเรียบร้อย และดูแลการ Deploy)  
  การหมุนเวียนนี้ทำให้เราเข้าใจความรู้สึกและภาระของเพื่อนร่วมทีม เกิดความเห็นอกเห็นใจ (Empathy) และทำงานสอดประสานกันได้อย่างราบรื่น
* **การทำงานแบบ Agile & Kanban:**  
  การกำหนดขอบเขตงาน Definition of Done (DoD) ของแต่ละ Sprint อย่างชัดเจน และการจำกัดงานที่อยู่ระหว่างทำ (WIP Limit) ช่วยลดความสับสนและทำให้ส่งมอบงานได้ตรงเวลาตามแผนงานทุกสัปดาห์

### 7. คุณค่าต่อสังคมและมุมมองต่อสิ่งแวดล้อม (Societal Impact & Domain Knowledge)
* **ความตระหนักรู้ด้านวิกฤตสิ่งแวดล้อม (Air Quality Awareness):**  
  ได้เรียนรู้และเข้าใจลึกซึ้งถึงมาตรฐานดัชนีคุณภาพอากาศ (US AQI / TH AQI) ผลกระทบของฝุ่นละอองขนาดเล็ก PM2.5 ตลอดจนตัวแปรสภาพอากาศต่าง ๆ
* **การเปลี่ยนข้อมูลให้เป็นพลังเตือนภัยสุขภาพ:**  
  ทำให้เราตระหนักว่า ทักษะการเขียนโปรแกรมสามารถนำมาสร้างสรรค์เครื่องมือที่ช่วยให้เพื่อนมนุษย์ โดยเฉพาะกลุ่มเปราะบาง (เด็ก ผู้สูงอายุ ผู้ป่วยโรคทางเดินหายใจ) สามารถประเมินความเสี่ยงและวางแผนการใช้ชีวิตประจำวันได้อย่างปลอดภัย

---

### สรุปบทเรียนสำคัญ (Key Takeaway)
> *"การสร้าง WeatherAQI Sense พิสูจน์ให้พวกเราเห็นว่า การเขียนโค้ดที่ยอดเยี่ยมไม่ได้วัดจากความยาวของบรรทัดคำสั่ง แต่วัดจากการออกแบบสถาปัตยกรรมที่ยืดหยุ่น ความปลอดภัยของระบบเมื่อเผชิญเหตุไม่คาดคิด ความสะดวกในการใช้งานของผู้ใช้จริง และการทำงานร่วมกันเป็นทีมอย่างมีระเบียบวินัย"*

ประสบการณ์จากโปรเจกต์นี้ได้เปลี่ยนพวกเราจากผู้ศึกษาทฤษฎีการเขียนสคริปต์ ให้ก้าวสู่การเป็น **นักพัฒนาซอฟต์แวร์ที่เข้าใจทั้งมิติทางเทคนิค กระบวนการวิศวกรรม และคุณค่าของชิ้นงานต่อผู้ใช้งานอย่างแท้จริง**
